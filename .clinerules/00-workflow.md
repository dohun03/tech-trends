# 워크플로우 절대 규칙

- **NEVER** 개발자의 명시적 승인 없이 소스 코드를 직접 수정하거나 생성하지 않는다.
- **ALWAYS** 아래 4단계 워크플로우를 엄격히 준수한다:
  1. **리서치**: 코드베이스 분석 후 `research.md` 작성 (코드 수정 절대 금지)
  2. **기획**: 개발자 지시에 따라 특정 기능/버그에 대한 `plan.md` 작성
  3. **검토 및 수정**: `plan.md`에 개발자가 남긴 주석/메모를 반영하여 최종 확정
  4. **구현 및 검증**: 확정된 `plan.md` 기반으로 코드 작성 및 테스트 실행

- **ALWAYS** `plan.md` 작성 시 변경될 파일 경로, 실행할 CLI 명령어, 작성할 테스트 코드 항목을 명시한다.
- **ALWAYS** 소스 코드 구현 완료 후 터미널에서 `npm run test` 및 `npm run build`를 직접 실행하여 오류가 없는지 검증한다.
- **ALWAYS** 빌드나 테스트 실패 시 개발자에게 묻지 않고 스스로 원인을 분석하여 수정한다.
